币安本机成交监控

个人自用的本地交易记录通知工具。程序在用户自己的 Windows 电脑上运行，读取币安公开的带单项目操作记录，发现新增记录后，通过用户授权的 Gmail 账号向其本人发送邮件。

隐私政策使用说明

应用功能

  • 定时读取公开订单历史与仓位历史，保存原始响应并去重。
  • 记录合约、开平动作、订单时间、均价、数量、名义金额与公开披露的盈亏。
  • 通过 Gmail API 发送本人订阅的逐笔通知，并核对发送结果以减少重复邮件。

本工具不登录币安、不跟单、不交易，也不请求交易权限。隐藏的当前持仓不会被推断为已知持仓。通知可能因网络、电脑关机、数据源或授权异常而延迟。

隐私政策

更新日期：2026年11月18日

本应用仅供所有者本人使用，不提供面向公众的注册或托管服务。

Google 数据访问与用途

应用请求 Gmail 发信权限，用于向所有者本人发送交易记录通知；请求 Gmail 只读权限，用于核验授权账号、查询已发送邮件中的通知标识以及确认发送结果，避免发送结果不明时重复发送。Google 的只读权限范围本身较广，但程序只为上述用途访问数据，不以此进行收件箱分析、广告画像或模型训练。

存储与共享

OAuth 授权令牌保存在所有者本机，使用 Windows 当前用户 DPAPI 加密。公开交易记录、通知状态、邮件标识及运行日志保存在本机。发送邮件时，邮件内容经 Google Gmail API 处理并存储在对应邮箱中。公开数据请求由币安处理。网站仅托管应用说明，不接收授权令牌、邮箱内容或交易数据库。

应用不出售 Google 用户数据，不向广告商提供数据，不使用这些数据训练通用人工智能模型。对 Google API 所获信息的使用和转移遵守 Google API Services User Data Policy，包括 Limited Use 要求。

保留、撤销和删除

本机记录保留至所有者自行清理。可在 Google 账号的第三方连接设置中撤销本应用授权，停止 Gmail 访问；可停止本机程序并删除本机令牌、数据库及日志。已发送邮件需在 Gmail 中另行删除。撤销授权不会自动删除已有邮件或本机历史。

联系：通过本项目的 GitHub Issues 联系维护者。请勿提交密码、令牌或私人邮件内容。

使用说明

本工具仅用于个人只读通知，不构成投资建议或交易执行服务。记录取自公开接口，可能存在延迟、缺失或源平台更新。名义金额为成交均价乘以成交数量，不代表保证金或账户投入。使用者自行核验记录，不能把通知视为当前仓位的完整证明。

本工具与 Binance、Google 没有隶属关系或官方背书。停止本机程序即可停止采集，移除 Windows 启动项即可关闭登录自启动。
